# ファイル管理 (FileXplorer) — Android用ファイル管理アプリ v1.1.0

Google Files のような使い勝手を目指した、Android用ファイル管理（エクスプローラー風）アプリです。
Kotlin・外部ライブラリなし（Android標準API + Kotlin標準ライブラリのみ）、minSdk 26 / targetSdk 34、パッケージ `jp.filexplorer.app`。

## 機能

### ホーム（Google Files 風）
- カテゴリから探す: 画像 / 動画 / 音声 / ドキュメント / 圧縮ファイル / アプリ(APK)
  （内部ストレージ内を再帰的に集めて新しい順に表示）
- 最近使ったファイル（更新日時順、最大100件）
- ダウンロードフォルダへのショートカット
- 内部ストレージの使用量バー（使用量 / 総容量 / 空き容量）
- お気に入りフォルダ（閲覧画面のメニューから登録するとホームに表示）

### 閲覧（エクスプローラー風）
- フォルダ優先の一覧（アイコン＋名前＋サイズ/項目数＋更新日時）、タップで遷移、Backで親へ（ルートではホームへ）
- パスバーのタップでパスを直接入力して移動
- 並び替え: 名前 / 日付 / サイズ / 種類、昇順・降順（設定は保存されます）
- 隠しファイル（ドット始まり）の表示 ON/OFF
- 検索: 現在のフォルダ（ホームでは内部ストレージ全体）以下を再帰検索

### ファイル操作
- 長押しで複数選択モード → コピー / 切り取り → 別フォルダで「ここに貼り付け」
  （同名がある場合は `名前 (1)` のように自動で重複回避）
- 新規フォルダ / 新規ファイル作成、名前変更（1件選択時）、削除（確認ダイアログ付き、フォルダは再帰削除）
- 詳細: パス、種類、サイズ（フォルダは中身の合計と件数）、更新日時、読み書き可否
- 共有（1件の詳細画面から、または外部アプリ連携）

### ファイルを開く
- 画像: アプリ内プレビュー（サムネイル表示）
- テキスト系（txt / md / json / xml / csv / log / コード類、200KBまで）: アプリ内プレビュー
- その他: 自前の ContentProvider 経由で外部アプリに開かせる（androidx不要の実装）

## 権限について
- Android 11以降: 内部ストレージ全体を見るには「すべてのファイルへのアクセス」が必要です。
  初回起動時に案内ダイアログが出ます（メニュー →「すべてのファイルへのアクセス設定」からも開けます）。
  許可しなくてもアプリ専用フォルダは使えます。
- Android 10以前: ストレージの読み書き権限を要求します。

## ビルド（リリースビルドはコマンド1つ）
Gradle/AGPを使わないオフライン手動ビルド（aapt2 + kotlinc + D8）です。UI は Jetpack Compose（Compose 1.7.6 / Material3）で、ライブラリは `tools/resolve.py` が Google Maven / Maven Central から `libs/` へ解決・取得します（初回ビルド時のみネットワークと python3 が必要）。デクサは build-tools 同梱 d8 の不具合を避けるため単体 R8 8.7.18 の D8 CLI を使い、マルチ dex で同梱します。

**ワンコマンドビルド**（テスト → ビルド → 署名 → 成果物表示まで一括）:

```sh
./build.sh      # Linux / macOS (引数なし=デバッグ署名 / release でリリース署名)
build.bat       # Windows (同上)
```

前提: JDK 17+（21推奨）/ Kotlin コンパイラ 2.0.21 / Android SDK（platform 34・build-tools 34.0.0）。SDK の場所は環境変数 `ANDROID_SDK_ROOT`（または `ANDROID_HOME`）で指定します。Kotlin は `KOTLINC` / `KOTLIN_HOME` / PATH の順に探します。

デフォルト（引数なし）ではデバッグ鍵で署名します（上書きインストール用）。配布用に自分のリリース鍵で署名する場合は、`release` を付け、環境変数でキーストアを指定してください（鍵情報はスクリプトに書かれません）。成果物は `dist/filexplorer-release.apk` になります:

```sh
RELEASE_KEYSTORE=/path/to/release.jks RELEASE_KEY_ALIAS=mykey RELEASE_KEYSTORE_PASS=xxxx ./build.sh release
```

個別に実行する場合:

```sh
./tests/run-tests.sh   # 単体テスト (FileOps: 67件、Kotlin)
./build-apk.sh         # build.sh の本体 (引数なし=debug / release で dist/filexplorer-release.apk)
```

Android Studio で開くための Gradle ファイル（AGP 8.7.3 + kotlin-android 2.0.21）も同梱しています。

- アプリアイコンを新しいアートワークに変更（アダプティブアイコン + 従来解像度の mipmap 一式、roundIcon 対応）
- ビルドパイプラインを Compose 対応に更新（Maven 版 Compose コンパイラプラグイン、ライブラリ AAR のリソースリンク、単体 R8 によるマルチ dex）。単体テスト 67 件はそのまま全パス

## v1.1.0 での変更（Kotlin化）
- 全ソース (FileOps / MainActivity / SimpleFileProvider / FileListAdapter) と単体テストを Java から Kotlin 2.0.21 に書き換え。機能・挙動は v1.0.1 と同一で、単体テスト66件もそのまま移植して全パス
- ビルドは kotlinc + d8 の手動パイプラインに変更（Kotlin ランタイムを同梱）。Gradle 側も Kotlin プラグイン対応に更新
- APK が 37KB → 約730KB になっています（Kotlin 標準ライブラリ分）

## v1.0.1 での修正（全ファイルレビュー）
- コピー/移動の安全化: フォルダを自分自身や配下へコピーすると無限再帰になる問題を禁止。貼り付け先は開始時点のフォルダに固定。同じフォルダへの切り取り貼り付けは無効化
- シンボリックリンクのループ対策: 合計サイズ・件数・削除・検索・収集でリンク先を辿らない＋深さ上限32
- 「最近」収集の正確化: 先着500件ではなく走査全体から新しい順に選ぶよう変更。走査カウンタの static 競合も解消
- 画面回転などで閲覧位置・選択・クリップボードが消える問題: 状態を保存/復元。戻る操作はパス判定から履歴スタック方式に変更（アプリ専用フォルダやお気に入りでも正しく親へ戻る）
- 削除とテキストプレビューをバックグラウンド化、画像プレビューは寸法からサンプリングして OOM を防止、一覧の行再利用でスクロール改善
- ContentProvider の強化: 読み取り専用に限定し、提供範囲を外部ストレージとアプリ用フォルダ配下だけに制限
- お気に入りを長押しで外せるようにした。権限ダイアログは起動時は初回だけ表示
- その他: サイズ表示の境界（1024 KB と出る問題）、並び替えの同値タイブレーク、検索の競合ガード、CI の actions を v5 に更新
